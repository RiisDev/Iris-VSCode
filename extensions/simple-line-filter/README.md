# Simple Line Filter

Keep or remove every line matching your **Find** search, using the real Find widget (so Match Case, Whole Word and Regex all work).

1. `Ctrl+F`, type a search, set the toggles.
2. Run **Simple Line Filter: Keep Lines Matching Find** (`Ctrl+Alt+K`) or **Remove Lines Matching Find** (`Ctrl+Alt+D`) — keybindings are active while the Find widget is open; the commands are also in the Command Palette.

Acts on the whole file. Undo with Ctrl+Z.
